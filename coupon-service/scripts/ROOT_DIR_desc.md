# ROOT_DIR 경로 계산 구문 전체 분석

아래 쉘 구문은 현재 실행 중인 스크립트 파일 위치를 기준으로  
상위 두 단계 디렉터리의 절대 경로를 계산하여 `ROOT_DIR` 변수에 저장한다.

    ROOT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")/../.." && pwd)"

---

## 1. 변수 할당

    ROOT_DIR="..."

- `ROOT_DIR`는 쉘 변수이다.
- `=` 오른쪽 값은 명령 치환 결과로 평가된다.
- 최종 결과 문자열이 `ROOT_DIR`에 저장된다.

---

## 2. 명령 치환 (Command Substitution)

    $( ... )

- 괄호 안의 명령을 서브쉘(subshell)에서 실행한다.
- 표준 출력(stdout)이 문자열로 치환된다.
- 서브쉘에서 실행된 `cd`는 현재 쉘의 작업 디렉터리에 영향을 주지 않는다.

---

## 3. BASH_SOURCE[0]

    ${BASH_SOURCE[0]}

- 현재 실행 중인 스크립트 또는 함수가 정의된 소스 파일의 경로를 담고 있다.
- `source`로 불러온 파일 내부에서도 해당 파일 경로를 가리킨다.
- 상대경로 또는 절대경로일 수 있다.
- `$0`보다 실제 소스 파일 위치 추적에 적합하다.

---

## 4. dirname

    dirname "${BASH_SOURCE[0]}"

- 파일 경로에서 파일명을 제거하고 디렉터리 경로만 반환한다.
- 예:
    - 입력: `/app/scripts/init.sh`
    - 출력: `/app/scripts`

---

## 5. 상대 경로 이동 (/../..)

    "$(dirname "${BASH_SOURCE[0]}")/../.."

- 현재 스크립트가 위치한 디렉터리를 기준으로 상위 두 단계 디렉터리를 의미한다.
- 이 단계에서는 아직 `..`가 포함된 논리적 경로 문자열이다.

---

## 6. cd

    cd "경로"

- 지정한 경로로 서브쉘의 현재 작업 디렉터리를 변경한다.
- 디렉터리가 존재하지 않으면 실패한다.

---

## 7. 논리 AND (&&)

    cd ... && pwd

- `cd`가 성공했을 때만 `pwd`를 실행한다.
- 잘못된 경로가 변수에 저장되는 것을 방지한다.

---

## 8. pwd

    pwd

- 현재 작업 디렉터리의 절대 경로를 출력한다.
- `..` 같은 상대 경로 요소가 제거된 정규화된 경로가 된다.

---

## 9. 전체 동작 흐름 요약

1. 현재 스크립트 파일 경로를 가져온다 (BASH_SOURCE[0])
2. 해당 파일이 위치한 디렉터리를 구한다 (dirname)
3. 상위 두 단계 경로를 만든다 (/../..)
4. 해당 경로로 이동한다 (cd)
5. 정규화된 절대 경로를 출력한다 (pwd)
6. 결과를 ROOT_DIR 변수에 저장한다

---

## 10. 최종 의미

현재 실행 중인 스크립트 파일을 기준으로  
두 단계 위에 있는 디렉터리의 절대 경로를 `ROOT_DIR`에 저장한다.

이 패턴은 모노레포, 멀티 모듈 프로젝트, 공통 설정 로딩 등에서  
프로젝트 루트 디렉터리를 계산할 때 널리 사용된다.
