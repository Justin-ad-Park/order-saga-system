# Appendix B. 공통 스크립트 사용법

이 프로젝트는 MSA 환경에서 서비스를 효율적으로 개발하고 테스트하기 위해 다양한 쉘 스크립트를 제공합니다. 이 스크립트들은 주로 `bin_common`, `bin_k8s`, `bin_test`, `bin_istio_test` 디렉토리에 위치합니다. 본 부록에서는 특히 여러 챕터에서 공통적으로 활용될 `bin_common` 디렉토리의 핵심 스크립트들을 설명하고 사용법을 안내합니다.

## 1. `bin_common` 디렉토리 개요

`bin_common` 디렉토리에는 MySQL 및 Kafka와 같은 인프라 환경을 준비하거나, 테스트 데이터를 초기화하는 등 프로젝트 전반에서 공통적으로 사용되는 유틸리티 스크립트들이 포함되어 있습니다.

주요 스크립트 목록:
*   `00_prepare_mysql_kafka.sh`: 로컬 MySQL과 Kafka를 준비합니다.
*   `05_reset_test_data.sh`: 테스트 데이터베이스의 데이터를 초기화합니다.

## 2. 핵심 공통 스크립트 상세 설명

### 2.1. `00_prepare_mysql_kafka.sh`

이 스크립트는 로컬 환경에서 MySQL과 Kafka를 Docker 컨테이너로 실행하고 필요한 초기 설정을 수행합니다. MSA 애플리케이션들을 실행하기 전에 이 스크립트를 먼저 실행하여 필수 인프라 환경을 준비해야 합니다.

**사용법:**
```bash
./bin_common/00_prepare_mysql_kafka.sh
```

**수행 작업:**
*   Docker Compose를 사용하여 MySQL 및 Kafka (Zookeeper 포함) 컨테이너를 시작합니다.
*   MySQL 데이터베이스(`coupon_db`, `point_db`, `order_orchestrator_db`)를 생성하고 초기 사용자를 설정합니다.
*   Kafka 토픽(`order-saga-events`)을 생성합니다.

**실행 전 요구사항:**
*   Docker Desktop이 설치되어 있고 실행 중이어야 합니다.

**예상 결과:**
스크립트가 성공적으로 실행되면 터미널에 MySQL 및 Kafka 컨테이너가 시작되고, 데이터베이스 및 토픽이 생성되었다는 메시지가 출력됩니다.

### 2.2. `05_reset_test_data.sh`

이 스크립트는 각 서비스의 테스트 데이터베이스(MySQL)를 초기 상태로 리셋합니다. 주로 통합 테스트를 실행하기 전이나, 새로운 테스트 시나리오를 시작하기 전에 일관된 테스트 환경을 구축하기 위해 사용됩니다.

**사용법:**
```bash
./bin_common/05_reset_test_data.sh
```

**수행 작업:**
*   `coupon_db`, `point_db`, `order_orchestrator_db` 데이터베이스의 핵심 테이블(`coupon`, `point`, `order_saga`, `outbox_message`, `coupon_reservation`, `point_reservation`) 데이터를 모두 삭제하고, `_snapshot` 테이블에 저장된 초기 데이터로 다시 채웁니다.
*   이는 각 서비스의 `src/main/resources/*_schema.sql` 파일에 정의된 초기 데이터 및 스냅샷 복원 로직을 활용합니다.

**예상 결과:**
스크립트가 성공적으로 실행되면 각 서비스 데이터베이스의 주요 테이블들이 초기 테스트 데이터 상태로 되돌려집니다. 터미널에는 각 DB가 리셋되었다는 메시지가 출력됩니다.

## 3. 스크립트 활용 팁

*   **실행 권한:** 쉘 스크립트(`*.sh`)는 실행 권한이 필요할 수 있습니다. 만약 실행되지 않는다면 `chmod +x ./bin_common/스크립트명.sh` 명령어로 실행 권한을 부여해 주세요.
*   **로그 확인:** 스크립트 실행 중 문제가 발생하면 터미널의 로그를 주의 깊게 살펴보고, 필요한 경우 스크립트 내용을 직접 확인하여 문제를 진단할 수 있습니다.
*   **재현성:** 이 스크립트들을 활용하여 언제든지 깨끗하고 동일한 개발/테스트 환경을 구축할 수 있습니다.

---
이 공통 스크립트들은 프로젝트의 필수적인 인프라를 준비하고, 반복 가능한 테스트 환경을 구축하는 데 큰 도움을 줍니다. 각 챕터의 실습 가이드에서 이 스크립트들을 적절히 활용하여 학습 효율을 높여보세요.
