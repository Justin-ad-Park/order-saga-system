# SAGA 세미나 커리큘럼 (MSA + EDA 주문 처리)

이 폴더는 Git 전체 히스토리를 기반으로, 프로젝트가 어떻게 설계·구현·검증·운영되는지 단계적으로 설명하기 위한 교육 자료 모음이다.

## 사용 방법
- 회차별 문서를 순서대로 진행한다. (01 ~ 13)
- 각 회차는 스토리라인, 데모/실습 명령어, 데이터셋을 포함한다.
- 공통 명령어/데이터셋은 `seminar/support/` 문서를 참고한다.

## 권장 진행 방식
- 회차당 60~90분
- 구성: 개념 20분 → 데모 20분 → 실습 30분 → Q&A 10분

## 사전 준비
- JDK 17+
- Docker, kubectl
- 프로젝트 루트에서 실행

## 보조 자료
- `seminar/support/commands.md`: 데모/실습 공통 명령어
- `seminar/support/datasets.md`: 테스트 데이터셋 명명 규칙
- `seminar/company/`: 회사별 스토리라인/교육 포커스 템플릿
- `seminar/assets/`: 아키텍처 다이어그램, 시퀀스 다이어그램 등 보조 자료 공간
